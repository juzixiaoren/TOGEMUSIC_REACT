## 问题列表

### 1. 后端DAO层问题

#### 1.1 song.py delete_song() 返回值检查错误
- **问题描述**：`delete_song()`方法返回字典，但`music.py`中检查`if not deleted`（字典总是真值，检查永远不会触发）
- **问题位置**：`backend/dao/song.py` 第58-68行，`backend/server/routes/music.py` 第1138-1141行
- **影响范围**：批量删除歌曲功能
- **修复状态**：已修复
- **测试状态**：通过（语法检查、逻辑审查：delete_song返回元组(success, song_info)，调用方正确解构）
- **备注**：修改delete_song()返回元组(success, song_info)，修改调用方检查逻辑

#### 1.2 DAO操作缺少异常处理
- **问题描述**：数据库操作可能抛出异常但未捕获，会导致程序崩溃
- **问题位置**：`backend/dao/song.py`、`backend/dao/user.py`、`backend/dao/playlist.py`
- **影响范围**：所有数据库操作
- **修复状态**：部分修复（song.py的get_song_by_id、add_song、set_play_status、delete_song已添加）
- **测试状态**：通过（语法检查、逻辑审查）
- **备注**：仅对song.py关键方法添加异常处理，user.py/playlist.py因可能影响现有功能跳过
